## 当前实现

| 能力 | 代码与证据边界 |
|---|---|
| 回复计划 | ResponsePlan 控制采集、澄清、身份、时间、已收资料和行动事实；模型仅补充登记的普通句子，初稿/重写/回退/最终发送完整校验 |
| 接待问答 | seller_profile 逐字段确认身份；程序使用新时钟按问题目标渲染时间，未解析或多时区地点澄清 |
| 货物事实 | CargoFacts/Readiness 共用于回复、goods、quote、摘要；包装数量/重量/尺寸/目的地分别有来源，商品净重不能满足包装重量 |
| 人工任务 | 当前 FlowRef、逐字段 FactRef 与原始 VerificationItems 持久化；同文不同货单事件不沿用旧确认；通知/认领/联系/回复/完成分别取证 |
| 人工介入 | 可信事件锚点的五分钟暂停、unknown 有界等待与来源更正重算；损坏暂停库阻断发送 |
| 发送收据 | 前后快照的唯一新增事件与完整正文绑定；发送前回读任务依赖、同步人工介入并用同一新时钟重组 |
| 时间门禁 | 可信新消息使用默认 20 秒成功发送间隔；普通消息使用五分钟门禁，缓存周期读取；没有端到端 SLA 证据 |
| 规则与隔离 | [规则清单](../scripts/reply_rules.registry.json) 区分 wired/partial/not_wired；默认 Offline 使用子进程临时根、自证与生产路径指纹 |

模块调用关系见 [项目地图](项目地图.md)，配置、人工任务操作与验证步骤见 [部署手册](../README_部署说明.md)。

## 验收结论与剩余限制

最新历史整改测试为 56 个测试文件、3036 个通过、0 个失败，LogicTests/IsolationChecks=PASS；3 项生产路径变化来源未证实，ProductionPathAudit=UNRESOLVED、Overall=BLOCKED-UNRESOLVED、退出码 3。本次冻结后复跑同样为 56 个文件、3036 个通过、0 个失败；生产审计 UNRESOLVED（4 项变化）、Overall=BLOCKED-UNRESOLVED、exit 3，详见 [发布记录](verification/release_0.1.1.md)，不能覆盖环境未验收结论。

- 真实模型质量、浏览器发送确认、通知到达及端到端延迟尚未验收；不依据桩模型或模拟时钟宣称上线效果。
- 发布补充的历史 20 场景回放为 594 个断言、82 个失败、exit 1，涉及旧生成契约与回复质量；保留失败证据与原断言，不能将默认 Offline 通过视为该回放通过。本版本按预发布代码快照发布。
- 人工任务只记录并验证执行证据，不会自动联系供应商；旧 contacted 或 resolved 标签不能单独授权实际行动陈述。
- 自证核验 PID、测试名、nonce、运行根和 marker，不能证明任意直接文件 IO 零越界；直接改写 AAR_RUNTIME_ROOT 环境变量仍不在切根登记覆盖内。
- 当前买家冲突消费持久化同流上下文；事实引擎不可读取时的跳过边界见整改交付，未宣称覆盖所有来源异常。
- 自然语言检查依赖受控模板、登记句子和现有解析规则；未知表达不意味着已获得业务授权。
- 旧 reply_rules.always/never 和 data_to_collect 仍无当前回复消费方；建议被接受或应用不能代替真实效果验证。
- backup/sync 是有限代码快照，不覆盖完整代码、工具与全部运行态。迁移前核对实际 Get-SkillPath 路径与完整备份。
