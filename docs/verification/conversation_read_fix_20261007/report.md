# 会话读取修复验收（2026-10-07）

本轮依据用户“顺带修复读取代码的缺陷”的明确授权修改代码。保留工作区此前未提交的修改，没有启动 monitor/watchdog，没有发送客户消息。

## 已修复

1. 联系人按归一化后的显示名精确匹配，预览正文、相似名字不能命中；同名多个候选返回 AMBIGUOUS_CONTACT。
2. 只认唯一可见的 content-header 和 message-container，要求页头属于该消息区域，消息行也属于它。移除全页面扫描消息及“挑最长页头候选”的逻辑。
3. 拒绝空消息及只有流程/噪声的页面。会话读取要求同一页头/区域连续两份非空语义快照一致，最多轮询 12 次，每次 500ms；变化或读取错误重置稳定检查。
4. 跨显示名复用同一消息集合时阻断。比较排序后的消息语义投影，保留重复数量，排除采样时间；单条有平台消息 ID 或多条带时间消息参与检测。
5. 监控读取与发送前后快照共用区域校验和逐条抽取。发送前先核对目标，再读取快照；错误/空快照直接中止发送。
6. monitor 的初始消息记录仅作暂存。发送适配器把本次实际读取的 before 快照保存并回读验证，再持久化 dispatching 阶段，之后才能输入/发送。重启对账与当次收据使用同一基线。
7. 读取或保存基线失败时返回 NotAttempted，monitor 不将其错误改写为 page:FAILED / delivery_ambiguous。dispatching 若已经部分落盘则保留保守状态。
8. 输入框及发送按钮限定在已核对的消息区域；发送前再次核对页头和区域节点。
9. 状态写入测试 send_attempt_receipt 新增隔离环境前置检查，禁止默认生产路径下直接运行。

涉及生产文件：scripts/monitor.ps1、scripts/lib/msg_extract_js.ps1、scripts/lib/outbound_receipts.ps1、scripts/lib/send.ps1、scripts/lib/send_attempts.ps1。新增 conversation_scope 和共享虚构 DOM 夹具，调整相关发送测试及测试清单。
