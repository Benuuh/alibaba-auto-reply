# v0.1.1 更新说明

本版本为预发布代码快照，完整环境与真实发送验收仍待完成。

## 更新

- 程序 ResponsePlan 控制追问、澄清、身份、时刻与行动事实，模型仅补充登记的普通说明；生成、回退和最终发送共用完整校验。
- CargoFacts/Readiness 统一回复、货物资料、报价提醒与摘要；区分商品净重与包装重量，保持真实箱/托盘单位及来源。
- 人工任务持久化当前货物流和逐字段证据；通知、认领、联系、供应商回复和完成分别验证，同文新货单不复用旧确认。
- 人工/unknown 介入按事件锚点有界等待；发送收据绑定唯一新增事件与完整正文，发送前重新核验依赖和时钟。
- 接待身份与逐目标时间问答、原子存储、规则清单、分层测试及 R01–R10 独立复核整改一并发布。
- 同步 README、部署说明、项目地图、当前状态和 CHANGELOG；本机路径、UTF-16 历史日志和配置模板完成脱敏，真实配置/凭据/客户数据/登录态不入库。

## 验证与未通过项

- 默认 Offline：56 个测试文件、3036 个断言通过、0 失败，逻辑与隔离 PASS。
- 生产路径审计：UNRESOLVED，4 项变化来源未证实，Overall=BLOCKED-UNRESOLVED，exit 3；未宣称完整环境验收通过。
- 历史 20 场景回放：594 个断言、82 个失败、exit 1，涉及旧生成契约预期及回复质量，保留原断言和失败证据，待专项复核。
- 105 个新增/修改 PowerShell 脚本的 PS5.1 语法与 BOM、索引敏感扫描、JSON 和主要文档链接检查通过。
