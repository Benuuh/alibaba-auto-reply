# v0.1.2 更新说明

本版本为预发布代码快照，真实页面与发送验收仍待完成。

## 更新

- 待回复列表出现一次即处理，取消现役入口的五分钟等待、20 秒新消息门槛、两轮确认与冷启动只观察；显式人工接管名单保留。
- 新旧识别只防同一次答复重复发送。发送前复核待回复成员、准确会话名及最新买家输入；送达不明或存储未闭环时先对账。
- 修复联系人误匹配、全页面混读、空快照与跨会话旧消息复用；要求唯一可见消息区域和连续稳定采样。读取重试一次仍失败，创建该会话的人工任务，继续处理其他客户。
- 模型恢复自然业务回复，解除九句登记话术限制。程序继续约束敏感索取、身份、时间、已确认事实及行动声明，并执行完整合规检查。
- 统一消息事件与来源证据、持久化发送尝试、真实收据、账本补写及调查恢复。修复无 rich 节点的附件遗漏、方向冲突和多客户待回复列表解析。
- 同步版本、文档与回归证据；公开资料脱敏，真实配置、凭据、客户会话、运行账本与浏览器登录态留在本机。
