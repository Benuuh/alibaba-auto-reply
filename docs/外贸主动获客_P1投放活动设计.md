# P1 投放活动设计 — 跨境物流/货代主动获客

> 配套文档：`外贸主动获客系统_设计文档.md`（总设计）
> 已确认决策：沿用跨境物流/货代业务 ｜ 不写回平台 CRM（纯只读）｜ 发信先全人工确认

## 1. 活动定义：打谁

跨境物流的获客逻辑和卖货**完全相反**：

| | 卖货 | 卖物流（我们） |
|---|---|---|
| 买家是谁 | 海外进口商/批发商 | **同样是从中国采购的人** |
| 触发时机 | 想采购 | **正在采购、正在发货、正在被物流折磨** |
| 最强信号 | 有采购需求 | **有进口记录 = 已经在发货 = 已有物流痛点** |
| 文案落点 | 产品好、价格优 | **时效、清关、甩柜、旺季爆仓、尾程派送** |

**所以海关数据在这个场景下的价值被放大**：一条"从中国进口、近 90 天有记录"的买家，不只是潜在客户，而是**已经确定在走中美线的客户**——你的服务对他来说是"换一家更好的"，而不是"说服他需要物流"。这比卖货的转化路径短得多。

## 2. 客户分层（v1，按优先级）

### Tier 1：美国亚马逊 FBA 卖家（最优）
- **痛点最具体**：头程时效、入仓预约、旺季爆仓、贴标换标、退货处理
- **决策链最短**：卖家老板/运营自己就能定，不用招投标
- **筛选信号**：Amazon 店铺存在 + 从中国进货 + 大件品类
- **为什么最优先**：痛点清晰 → 文案好写 → 回复率高

### Tier 2：美国中小进口商 / 品牌商
- **痛点**：清关合规、DDP 报价、尾程派送、账期
- **筛选信号**：海关记录（从中国进口）+ 规模 10–200 人
- **特点**：单量比 FBA 卖家大，但决策慢一些

### Tier 3：美国批发/分销商（家具、户外、健身器材）
- **特点**：大件、海运为主、货值高、复购稳定
- **筛选信号**：HS 编码集中在 94xx（家具）/ 95xx（户外健身）/ 87xx（骑行）

> **暂不碰**：加拿大/澳洲（CASL 与 Spam Act 是选择加入制，冷邮件不可行）；欧盟需 LIA 文档，放 P4 之后单独处理。

## 3. 平台筛选条件（lg_source_waimao 的 Query）

```jsonc
{
  "country": ["US"],                        // 只要美国
  "importer": true,                         // 有进口记录
  "trade_from": ["CN", "VN", "IN"],         // 从中国/东南亚采购 → 走跨太平洋线
  "last_shipment_days": 180,                // 近半年有记录 = 还活着
  "hs_codes": ["9403", "9401", "9506", "8711", "8504"],  // 家具/户外健身/骑行/电源
  "company_size": ["11-50", "51-200", "201-500"],
  "buyer_keywords": ["importer", "wholesale", "distributor", "brand", "ecommerce"],
  "limit": 50                               // 单次任务限量,跑完即止
}
```

**HS 编码选择理由**：优先挑**体积大 / 重量大 / 货值中等**的品类——这类货物流成本占比高，卖家对物流价格敏感、对服务依赖强，正是货代能吃下的生意。小件轻货（3C 配件）物流成本占比低，卖家不care。

### 关键词（用于搜索型数据源）
```
amazon fba seller / fba prep / 3pl / importer / wholesale distributor
furniture importer / outdoor furniture / home goods distributor
ddp shipping / customs broker / freight forwarder(排除同行)
```
> ⚠️ 需要排除同行：`freight forwarder` / `logistics company` / `shipping agent` 出现时**降权或剔除**，否则名单里一半是竞争对手。

## 4. 打分权重（物流场景专用，覆盖总设计 §5 的通用版）

| 信号 | 权重 | 理由 |
|---|---|---|
| 近 90 天有中国进口记录 | **+30** | 最强信号：正在发货 |
| 亚马逊卖家特征 | **+25** | FBA 头程痛点最明确 |
| HS 编码属大件品类 | +15 | 物流成本占比高，货代有价值 |
| 规模 11–200 人 | +10 | 有量但决策快 |
| 决策人邮箱（person + ok） | +15 | 直达老板/运营 |
| 有官网且有物流相关页面 | +5 | 可做个性化素材 |
| 邮箱 catch-all | −10 | 送达不确定 |
| 同行（货代/物流公司） | **−100** | 直接排除 |
| 已有固定物流合作伙伴迹象 | −5 | 换供应商门槛 |

**门槛：score ≥ 60 才进入发信队列。** 低于 60 的进"观察池"，不浪费触达额度。

## 5. 开发信骨架（定位：同行对比，不是产品推销）

### 核心策略：先给价值，不要报价单

第一封**不发价格**。发一句能让他觉得"这人懂我的痛点"的观察，然后问一个容易回答的问题。

**Step 1 — 开场（观察 + 提问）**
```
主题：Quick question about your FBA inbound from China

Hi {first_name},

Saw that {company} has been importing {category} from China —
are you currently running FBA inbound through {port_of_entry}?

We handle China → US FBA头程 for {category} sellers:
- 海运整柜/拼箱 + 空运急补
- 清关 + DDP 门到门（含关税）
- 贴标/换标/入仓预约（Amazon 合规）

Most of our clients' pain isn't the freight rate —
it's the 甩柜 and 旺季爆仓 in Q4.

Worth a 10-minute call? Or just reply with your current
lead time and I'll tell you honestly if we can beat it.

{signature}  ← 必须含真实公司名 + 实体地址 + 退订方式
```

**为什么这样写**：
- 开头一句**证明你看过他的资料**（提到品类/进口记录），不是群发感
- 主动提痛点（甩柜、爆仓）→ 显示行业理解
- **不报价**，降低防备；给一个"低门槛回复"（报个时效就行）
- 明确可比性（"能不能比你现在的快"）→ 把对话引到具体比较上

**Step 2 — 案例（4 天后，未回复才发）**
```
主题：Re: {category} inbound — one number

Hi {first_name},

Quick follow-up. One recent case for context:

{category} seller, {volume} CBM/month from {origin_port}:
- Previous lead time: 45 days door-to-door
- With us: 28 days, incl. customs + FBA appointment

Same route, same season. Happy to send the breakdown
if useful — no obligation.

{signature}
```

**Step 3 — 收尾（5 天后，未回复才发）**
```
主题：Closing the loop

Hi {first_name},

Won't keep filling your inbox. If China→US inbound
isn't a priority right now, no problem at all.

If it becomes one — especially heading into Q4 —
just reply "rates" and I'll send current pricing
for your lane.

{signature}
```

> **Step 3 之后停止。** 不回复就是"不感兴趣"的强信号，继续追只会伤域名信誉。

## 6. 合规字段（每封强制注入，不可省略）

| 要素 | 内容 |
|---|---|
| 真实发件人 | 姓名 + 公司全称 |
| 实体地址 | 公司注册地址（CAN-SPAM 硬要求） |
| 退订方式 | 一键退订链接 + "reply STOP" 均可 |
| 语种 | 英文（美国市场） |
| 免误导 | 主题不得伪装 Re: 已有对话（**Step 2/3 的 Re: 是真回复链，不算伪装**；首次触达不得用 Re:） |

## 7. 节奏与配额（warmup 版）

| 周 | 日发信上限 | 说明 |
|---|---|---|
| 第 1 周 | 10 | 全人工确认，重点看文案效果与回复率 |
| 第 2 周 | 20 | 若退信率 <3% 则进入下一周 |
| 第 3 周 | 40 | |
| 第 4 周+ | ≤80 | 视退信率动态调整 |

**降级规则**：退信率 >5% → 立即回退到上一周量级 + 企微告警。

**序列间隔**：Step1 → Step2 = 4 天，Step2 → Step3 = 5 天。**只发工作日**（美国时区周二至周四上午送达效果最好）。

## 8. 成功指标（先定义，否则没法判断好坏）

| 指标 | 目标 | 说明 |
|---|---|---|
| 送达率 | >95% | 低于此说明域名/名单有问题 |
| 退信率 | **<3%** | 核心健康指标，>5% 立即降级 |
| 打开率 | >30% | 仅供参考（苹果 MPP 会干扰） |
| **回复率** | **>3%** | 真正的核心指标 |
| 有效意向 | >1% | 回复中明确谈时效/价格的比例 |
| 429 次数 | 0 | 平台风控指标 |

> 物流行业的冷邮件回复率经验值在 2–5%。**如果长期 <1%，问题通常在名单质量而不是文案**——先回头查筛选条件。

## 9. 与总设计的差异点汇总

| 项 | 总设计 | P1 物流活动实际 |
|---|---|---|
| 写回平台 CRM | 可选 | **不做**（纯只读，风控压力大幅降低） |
| 发信确认 | 可配 | **全人工确认** |
| 打分权重 | 通用版 | 物流专用版（见 §4） |
| 目标市场 | 欧美 | **仅美国**（CA/AU 排除，EU 延后） |
| 序列长度 | 可配 | 固定 3 步 |

## 10. 待你补充的业务信息（写文案前必须知道）

1. **你实际能提供的服务范围**：只做中美专线？还是也做东南亚/欧洲？海空运都做吗？DDP 能覆盖吗？（文案里承诺的服务必须是真能做的）
2. **优势卖点**：自有渠道？价格优势？清关能力？海外仓？——决定 Step 2 案例怎么写
3. **真实案例数据**：有没有可用作 Step 2 的真实时效对比？（可脱敏，但不能编——编的案例一旦被追问就崩）
4. **发信主体**：用哪个域名/邮箱发？是否已配置 SPF/DKIM/DMARC？
5. **现有客户来源**：你现在的客户主要从哪来？（阿里询盘？转介绍？）——有助于校准名单筛选条件
