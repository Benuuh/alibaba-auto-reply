- `HASH|count` 没有保存可比较的逐条时间。窗口截断后等条数同文的新消息，以及等条数同原文的附件替换，无法仅凭现有格式证明新消息；本次不扩展账本，不能声称覆盖所有窗口变化。

- 本次 mock 外部 I/O，未验证真实 DOM 更新时效、真实模型质量、文件下载/解析、发送锁底层跨进程行为、页面点击/回执或通知投递。最终发送身份返回值的处理已离线覆盖，底层发送实现未改动。
- 进程上下文重建验证保留账本去重；本次不新增发送时间持久化。沿用原 lastSendAt 生命周期，历史键本身不能恢复完整发送间隔。
